<Section kind="why">

Casi todo programa de ML empieza igual: cargar una tabla de datos y **separar** las columnas de entrada (`X`) de la columna que queremos predecir (`y`), y las filas de entrenamiento de las de prueba. Después, a menudo hay que **cambiar la forma** de los datos porque un modelo la exige: una LSTM, por ejemplo, espera un array 3D `[muestras, pasos de tiempo, características]`.

Indexar, hacer *slicing* y `reshape` con soltura evita una enorme cantidad de errores de forma (`shape mismatch`), los más frecuentes en ML.

</Section>

<Section kind="intuition">

Un array 2D es una cuadrícula con **coordenadas** `[fila, columna]`, contando desde 0. Puedes elegir:

- **una posición** con enteros: `data[1, 2]`;
- **un rango** con slices `desde:hasta:paso` (el `hasta` no se incluye): `data[0:2, :]`;
- **desde el final** con índices negativos: `-1` es el último.

Escribe expresiones (o pulsa los ejemplos) y observa qué celdas se seleccionan y qué **forma** tiene el resultado:

<Figure title="Explorador de indexado y slicing" caption="Prueba a escribir data[3] o data[0, 0, 0] para ver los errores que daría NumPy.">
  <ArrayExplorer />
</Figure>

<Callout kind="tip">
Un **índice entero elimina una dimensión**; un **slice la conserva**. `data[0]` es un vector `(3,)`, pero `data[0:1]` es una matriz `(1, 3)` con una sola fila.
</Callout>

`reshape` reorganiza los **mismos** elementos con otra forma. NumPy los lee fila a fila (orden "C"), así que el orden de los datos nunca cambia, solo cómo se agrupan:

<Figure title="reshape: mismos datos, otra forma" caption="El color y el número identifican cada elemento. Prueba una forma imposible como 5, 3 o usa -1 para que NumPy calcule una dimensión.">

</Figure>

</Section>

<Section kind="formal">

Para un eje de longitud $n$, un índice negativo $-k$ equivale a $n - k$. Un slice `a:b:s` selecciona los índices

<Formula label="Índices de un slice" tex="\{\,a,\ a+s,\ a+2s,\ \dots\,\} \cap [a, b) \qquad (s > 0)" reading="el conjunto formado por a, a más s, a más dos s, y así sucesivamente, intersecado con el intervalo que va desde a (incluido) hasta b (excluido), siendo el paso s positivo">
  Si se omite `a` vale 0; si se omite `b`, vale $n$; si se omite `s`, vale 1. Los límites fuera de rango se recortan (no dan error), mientras que un índice entero fuera de rango lanza `IndexError`.
</Formula>

<Formula label="reshape válido" tex="(n_1, \dots, n_d) \to (m_1, \dots, m_k) \quad\text{solo si}\quad \prod_i n_i = \prod_j m_j" reading="la forma n sub 1, …, n sub d se puede convertir en la forma m sub 1, …, m sub k solo si el producto de todas las n sub i es igual al producto de todas las m sub j">
  Una de las $m_j$ puede ser $-1$: NumPy la calcula para que el producto cuadre.
</Formula>

| Patrón | Significado | Forma desde `(n, d)` |
|---|---|---|
| `data[:, :-1]` | todas las columnas salvo la última (X) | `(n, d-1)` |
| `data[:, -1]` | última columna (y) | `(n,)` |
| `data[:k, :]` | primeras k filas (entrenamiento) | `(k, d)` |
| `data[k:, :]` | resto de filas (prueba) | `(n-k, d)` |
| `x.reshape(-1, 1)` | vector como columna | `(n, 1)` |

</Section>

<Section kind="example">

<WorkedExample>
<Problem>
Con el siguiente dataset (las dos primeras columnas son entradas y la última es la salida), obtén X, y, y una división 2/1 en entrenamiento/prueba. Después prepara X para una LSTM.

$$
\texttt{data} = \begin{bmatrix}11&22&33\\44&55&66\\77&88&99\end{bmatrix}
$$
</Problem>
<Step>
`data.shape` es `(3, 3)`. Las entradas son todas las filas y las columnas 0 y 1: `X = data[:, :-1]` → forma `(3, 2)`:

$$
X = \begin{bmatrix}11&22\\44&55\\77&88\end{bmatrix}
$$
</Step>
<Step>
La salida es la última columna con un índice entero, para obtener un vector: `y = data[:, -1]` → forma `(3,)`.

$$
y = \begin{bmatrix}33 & 66 & 99\end{bmatrix}
$$

Si hubiéramos usado un slice (`data[:, -1:]`), obtendríamos en cambio una matriz columna de forma `(3, 1)`.
</Step>
<Step>
Entrenamiento y prueba se separan por filas: `train = data[:2, :]` (filas 0 y 1) y `test = data[2:, :]` (fila 2).

$$
\texttt{train} = \begin{bmatrix}11&22&33\\44&55&66\end{bmatrix} \qquad \texttt{test} = \begin{bmatrix}77&88&99\end{bmatrix}
$$
</Step>
<Step>
La LSTM espera `[muestras, pasos, características]`. Interpretamos cada columna de X como un paso temporal con 1 característica: `X.reshape(3, 2, 1)`. Siguen siendo 6 elementos ($3\cdot2 = 3\cdot2\cdot1$); cada muestra pasa a ser una pequeña matriz de 2 pasos × 1 característica:

$$
\texttt{X[0]} = \begin{bmatrix}11\\22\end{bmatrix},\qquad \texttt{X[1]} = \begin{bmatrix}44\\55\end{bmatrix},\qquad \texttt{X[2]} = \begin{bmatrix}77\\88\end{bmatrix}
$$
</Step>
</WorkedExample>

</Section>

<Section kind="ml">

- `X, y = data[:, :-1], data[:, -1]` aparece en casi todos los tutoriales de ML: ahora sabes exactamente qué formas produce.
- Muchos errores de scikit-learn ("Expected 2D array, got 1D array instead") se resuelven con `x.reshape(-1, 1)`.
- Las redes recurrentes y convolucionales esperan arrays 3D o 4D: `reshape` adapta los datos sin copiarlos.

<KeyTakeaways>
- Los índices empiezan en 0; los negativos cuentan desde el final.
- Un entero elimina una dimensión; un slice `a:b` la conserva y excluye `b`.
- `reshape` conserva el número de elementos y su orden; `-1` calcula una dimensión.
</KeyTakeaways>

</Section>
